## F05 管理端基础框架

实现内容：

- 登录页、基础布局、侧边导航、顶部用户入口及面包屑导航。
- 登录态路由处理、权限受限提示、403 与 404 页面。
- 登录后进入用户有权访问的页面；没有业务菜单时提供清晰提示，并保留个人中心和退出入口。
- 统一处理加载、空数据、表单校验、操作确认、请求失败和登录过期。
- 菜单及按钮可见性与后端权限保持一致，支持刷新页面和直接访问链接。

验收：登录后刷新和直接访问合法链接正常；无权限页面、失效登录和不存在的地址各有明确反馈；只读账号界面与实际可调用权限一致。
