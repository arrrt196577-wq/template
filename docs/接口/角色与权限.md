## 模块接口清单（建议路径）

路径均相对于 `/api/v1`，路径和 DTO 尚未实现；具体权限码目录待确定；系统管理员身份及最后一个可用管理员保护必须由服务端验证。通用请求、响应、状态码、分页和校验遵循[公共规范](公共规范.md)，功能范围与验收见对应业务文档。未给出 DTO 的接口，须在开发前补齐字段、约束、成功与失败响应，不能根据清单推定完整契约。

| 模块 | 方法与路径 | 用途与授权边界 |
| --- | --- | --- |
| 角色 | `GET /roles`、`GET /roles/{id}` | 角色列表及详情，要求角色查询权限 |
| 角色 | `POST /roles`、`PATCH /roles/{id}` | 系统管理员创建、修改或停用角色 |
| 权限 | `GET /permissions` | 返回代码维护的固定权限目录，要求系统管理员身份，不提供权限定义写接口 |
| 授权 | `PUT /roles/{id}/permissions` | 系统管理员整体替换角色权限，执行管理员保护 |

- 角色不提供删除；权限目录不提供编辑。角色权限关联整体替换须明确集合上限、去重、关联目标存在且有效等校验；空数组表示撤销全部关联，仍受管理员保护约束。
