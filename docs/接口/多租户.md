# 多租户接口边界

- 拆分日期：2026-11-06（Asia/Hong_Kong）。
- 来源：原API 规划；本次按模块迁移，不代表新增实现或确认待定方案。
- 状态：具体已实现、已确定及待定范围见正文；规划内容不能作为功能已实现的依据。
- 导航：[文档索引](../文档索引.md)、[多租户业务](../业务/多租户.md)、[认证接口](认证与个人中心.md)、[公共规范](公共规范.md)。

- 多租户需求已明确，但隔离方式、账号归属与平台身份仍是待确认建议，尚未落实共同契约；本文件不新增已确定路径或 DTO。
- 登录须明确目标租户及管理端/会员身份；`tenantCode` 为候选字段，域名映射为候选替代，具体入口与字段待定。
- 会话绑定租户，请求不能用客户端租户值覆盖已认证范围；每次请求校验租户状态，缺失租户上下文不能降级为全表查询。
- 已有接口权限但资源属于其他租户时建议返回 404，须在共同契约中确认。
- 平台入口与跨租户操作授权单独定义，不能通过客户端 `skipTenant` 或超级管理员身份自动绕过隔离。
- Java、Go 与前端补齐共同契约后再实现；业务身份、约束、并发失效及双租户验收以[多租户业务规划](../业务/多租户.md)为准。
