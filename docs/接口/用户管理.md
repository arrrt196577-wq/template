## 模块接口清单（建议路径）

路径均相对于 `/api/v1`，路径和 DTO 尚未实现；具体权限码目录待确定；系统管理员身份及最后一个可用管理员保护必须由服务端验证。通用请求、响应、状态码、分页和校验遵循[公共规范](公共规范.md)，功能范围与验收见对应业务文档。未给出 DTO 的接口，须在开发前补齐字段、约束、成功与失败响应，不能根据清单推定完整契约。

| 模块 | 方法与路径 | 用途与授权边界 |
| --- | --- | --- |
| 用户 | `GET /users`、`GET /users/{id}` | 用户列表及编辑所需详情，要求用户查询权限 |
| 用户 | `POST /users`、`PATCH /users/{id}` | 创建、修改基本资料及启用状态，要求相应管理权限，不能夹带角色或密码变更 |
| 用户 | `PUT /users/{id}/roles` | 整体替换角色关联，单独验证分配角色权限及管理员保护 |
| 用户 | `POST /users/{id}/reset-password` | 系统管理员重置密码，撤销该账号全部旧凭据 |

- 用户不提供删除；用户角色关联整体替换须明确集合上限、去重、关联目标存在且有效等校验；空数组表示撤销全部关联，仍受管理员保护约束。
