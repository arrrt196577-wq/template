# 文档索引

- 创建日期：2026-10-20（Asia/Hong_Kong）
- 用途：供开发者与 AI 按任务定位项目文档。
- 当前实现状态：前端已有空白骨架，Java、Go 后端均有启动、健康检查与默认拒绝骨架；Go 已接入配置、日志、数据库连接池、显式迁移和基础验证，均无业务功能。运行说明见 [前端 README](../frontend-template/README.md)、[Java 后端 README](../backend-template/java/README.md)、[Go 后端 README](../backend-template/go/README.md)，规划和候选建议不代表已实现或已确定选型。

## 阅读方式

1. 先阅读根目录 [AGENTS.md](../AGENTS.md)，了解项目边界、文档规范与协作要求。
2. 通过本索引选择与当前任务相关的文档；涉及技术选型或功能实现时，先阅读技术栈规划、业务范围与阶段及对应模块的业务规划。
   涉及接口或鉴权设计时，再阅读接口公共规范和对应模块的接口规划，注意区分已明确前提与建议基线。
3. 本索引仅用于导航，具体约定和状态以对应正文为准；实现情况还须核对实际代码与配置，不能仅凭规划判断。

## 维护要求

- 新增、删除或重命名 `docs/` 下的文档时，同步更新本索引的链接和说明；调整文档范围或状态时，同步更新对应摘要。
- 业务和接口设计按模块分别放在 `业务/`、`接口/`，新增模块同步登记；公共约定通过引用复用，不在各模块复制。
- 索引保持简短，仅维护导航、用途与状态，不复制正文中的详细方案或验收清单。
- 本索引修订时保留原文件名；新增文档仍遵循 `AGENTS.md` 中的命名规范。
